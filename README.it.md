# 🩸 Sync — tracker del ciclo

App per tracciare il ciclo mestruale con i **dati salvati solo sul tuo dispositivo**: nessun account, nessun server, niente pubblicità.

🔗 **App online:** https://syncycle.onrender.com

## Cosa fa
- **Oggi** — fase del ciclo, giorno e previsioni (prossimo ciclo, ovulazione, finestra fertile)
- **Calendario** — giorni di flusso, previsti, fertili e ovulazione
- **Registra** — flusso, sintomi, umore, rapporti, temperatura basale e muco cervicale
- **Consigli** per fase del ciclo — attività fisica, alimentazione, mente (cycle syncing)
- **Grafici** — lunghezza dei cicli, curva della temperatura basale, sintomi più frequenti
- **Promemoria** (ciclo, finestra fertile, pillola) con notifiche opzionali
- Disponibile in **italiano e inglese**, installabile come **PWA**, funziona offline

## Privacy
Tutti i dati restano nel browser del tuo dispositivo. L'hosting consegna solo la pagina: non vede né salva nulla.

## Tecnologie
HTML, CSS e JavaScript puri (nessuna dipendenza). App statica, PWA.
